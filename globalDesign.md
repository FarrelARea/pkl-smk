# DESIGN SYSTEM TOKENS: SIMASKANSA SYSTEM

## 1. Color Palette
- Primary Blue (Buttons, Active States): #1E5EF3 (Bright, professional corporate blue)
- Dark Text / Headings: #0A1C40 (Deep navy for high contrast readability)
- Soft Accent Blue (Backgrounds, Hover): #F0F5FF
- Alert/Accent Yellow (Sparks, Highlights): #FACC15
- Border / Neutral Stroke: #E2E8F0
- Muted Text (Placeholders): #94A3B8
- Pure White (Card backgrounds): #FFFFFF

## 2. Typography
- Heading Font: 'Poppins' or 'Nunito' (Provides a modern yet friendly, slightly rounded look that matches the UI illustrations)
- Body & Table Font: 'Inter' or 'Plus Jakarta Sans' (Highly readable for data-dense layouts)
- Font Weights: Light (300), Regular (400), Medium (500), Semibold (600), Bold (700)

## 3. Surface & Effects
- Main Card Corner Radius: 24px (Large rounded corners for container cards)
- Component Corner Radius: 12px to 16px (For inputs, buttons, and table containers)
- Box Shadow (Soft Depth): `box-shadow: 0px 10px 30px rgba(30, 94, 243, 0.05);` (Subtle blue-tinted shadow)
