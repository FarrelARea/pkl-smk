# COMPONENT SPEC: BUTTONS

## 1. Primary Button (e.g., Save, Submit, Add New)
- Background: #1E5EF3
- Text Color: #FFFFFF
- Font Weight: 600 (Semibold)
- Corner Radius: 12px or 'full' (depending on context, but 12px matches the inputs)
- Padding: 12px 24px
- Hover State: Brightness transition or darken slightly (#164EC7)
- Optional Accent: Include a subtle micro-interaction icon (like the paper airplane on the login button) for main action buttons.

## 2. Secondary Button (e.g., Cancel, Filter, Export)
- Background: #F0F5FF (Soft light blue)
- Border: None
- Text Color: #1E5EF3
- Font Weight: 500 (Medium)
- Corner Radius: 12px

## 3. Outline Button
- Background: Transparent
- Border: 1.5px solid #1E5EF3
- Text Color: #1E5EF3
- Font Weight: 500
- Corner Radius: 12px
