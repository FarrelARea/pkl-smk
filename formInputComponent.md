# COMPONENT SPEC: FORM INPUTS

## 1. Text Field / Select Box
- Background: #FFFFFF
- Border: 1px solid #CBD5E1 (Soft gray)
- Corner Radius: 12px
- Padding: 14px 16px (Spacious and touch-friendly)
- Font Size: 14px or 16px
- Placeholder Text Color: #94A3B8

## 2. Input States
- Focus State: Border changes to #1E5EF3 with a soft outer glow (`box-shadow: 0 0 0 4px rgba(30, 94, 243, 0.1);`)
- Icon Integration: Left-aligned icons should use a soft blue background container, just like the envelope and lock icons in the login screen.

## 3. Labels
- Position: Above the input field (Top-aligned)
- Typography: Uppercase, Semibold, Size: 12px, Color: #0A1C40 (Matches the 'EMAIL' and 'PASSWORD' labels in the screenshot)
